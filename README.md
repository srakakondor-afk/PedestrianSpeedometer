# Пешеходный спидометр: проект Android

Приложение-оболочка (WebView) вокруг страницы `app/src/main/assets/index.html`.
Все функции спидометра работают внутри: GPS-скорость, темп, дистанция, средняя и максимальная скорость, шаги, калории, отрезки, сигнал при выходе из целевого диапазона.

## Способ 1. Android Studio

1. Распакуйте архив и откройте папку проекта в Android Studio (File → Open).
2. Дождитесь синхронизации Gradle (понадобится интернет).
3. Меню Build → Build Bundle(s) / APK(s) → Build APK(s).
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

## Способ 2. GitHub Actions (без установки чего-либо)

1. Создайте на GitHub пустой репозиторий и загрузите в него содержимое этой папки (включая скрытую папку `.github`).
2. Откройте вкладку Actions. Сборка запустится сама, или нажмите «Run workflow».
3. Когда она завершится, скачайте файл `pedestrian-speedometer-apk` из раздела Artifacts на странице запуска. Внутри `app-debug.apk`.

## Способ 3. Командная строка

Нужны JDK 17, Android SDK (платформа 34) и Gradle 8.9 или новее:

    gradle assembleDebug

## Установка на телефон

Перенесите `app-debug.apk` на телефон и откройте его. Android попросит разрешить установку из этого источника. При первом запуске разрешите доступ к местоположению.

## Что важно

- Экран не гаснет, пока приложение открыто. Если заблокировать телефон или свернуть приложение, Android остановит GPS-слежение внутри WebView.
- Шрифты подгружаются из Google Fonts. Без интернета используется системный шрифт, на работу это не влияет.
- Подпись у debug-сборки отладочная. Для публикации в магазине нужна release-сборка с вашим ключом.
